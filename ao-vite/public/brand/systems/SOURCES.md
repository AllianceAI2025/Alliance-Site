# System marks

These marks identify the source or destination application in this local illustrative demo; they do not indicate a connected account. Original artwork is displayed without recoloring or distortion.

- Salesforce: https://www.salesforce.com/content/dam/sfdc-docs/www/logos/logo-salesforce.svg ; publisher collection: https://www.salesforce.com/news/media-collection/company-logos-and-video/
- Dynamics 365 and Project Operations: official SVG download linked from https://learn.microsoft.com/en-us/dynamics365/get-started/icons
- Outlook, Teams, SharePoint, Project and Word: Microsoft product SVGs mirrored at https://github.com/DamoBird365/microsoft-cloud-icons/tree/master/icons/microsoft-365 . Microsoft architecture artwork guidance: https://learn.microsoft.com/en-us/previous-versions/microsoft-365/solutions/architecture-icons-templates

AllianceOne marks remain the existing artwork from Alliance Site.
